# Народные росписи России

Распакуйте архив целиком и откройте папку rospisi-atlas в VS Code через «Файл → Открыть папку». При установленном Google Chrome нажмите F5. Также можно открыть docs/index.html двойным щелчком в проводнике.

Для работы через локальный сервер откройте терминал VS Code в папке проекта. Если установлен Python 3, выполните на Windows «py -m http.server 8000 --bind 127.0.0.1 --directory docs», на macOS или Linux — «python3 -m http.server 8000 --bind 127.0.0.1 --directory docs». Откройте http://127.0.0.1:8000/ в браузере. Чтобы остановить сервер, нажмите Ctrl+C.

## Где редактировать сайт

- docs/index.html — главная страница.
- docs/articles/ — 12 страниц атласа.
- docs/*.css — оформление и темы.
- docs/*.js — данные, тест и поведение интерфейса.
- docs/assets/ — изображения и знак сайта.
- scripts/ — вспомогательные скрипты и шаблон для генерации страниц и вопросов. Для просмотра и редактирования готового сайта достаточно папки docs. Генераторы перезаписывают создаваемые ими файлы.

Для сохранения прогресса открывайте сайт в одном браузере по одному адресу.

## Сверка с практическими работами

| Работа | Где посмотреть |
|---|---|
| ПР2. CSS и блочная модель | docs/style.css и docs/enhancements.css. Внешняя таблица стилей, сброс отступов, border-box, ограничение ширины, рамки, тени, состояния наведения. Карточки в каталоге содержат заголовок, дату, описание и подвал с тегом. |
| ПР3. Flexbox | Шапка и меню используют flex. На странице любой росписи основной текст и оглавление образуют две колонки с flex: 7 и flex: 3. При ширине до 768 px оглавление перемещается под статью. |
| ПР4. JavaScript | В шапке переключите тему. В каталоге нажмите «Лайк» несколько раз у разных росписей. Кнопка «Читать далее» раскрывает описание, «Свернуть» снова оставляет одну строку. Счётчик одной росписи общий для её карточки и страницы при запуске через локальный сервер. Оценка полезности и избранное работают отдельно. |
| ПР5. Данные, рендеринг и поиск | docs/data.js содержит массив traditions. В docs/enhancements.js функция renderArticles заполняет пустой postsContainer. Введите «Мстера», слово из описания или нажмите тег под карточкой. Очистите поле, чтобы вернуть результаты при текущих фильтрах. |
| ПР6. Git и GitHub Pages | Выполните шаги ниже в своём аккаунте. Папка docs подготовлена для публикации из ветки main. |

Для эксперимента из ПР2 откройте карточку в инструментах разработчика, измените padding у .card-summary и посмотрите на расстояние от текста до края. Сравните правила h3 и article header h3 в панели стилей: второе правило при прочих равных имеет больший вес. Для проверки через расширение Live Server откройте контекстное меню docs/index.html и выберите Open with Live Server.

## ПР6. Публикация из VS Code

1. Распакуйте новую копию проекта, откройте папку с этим README и выберите «Терминал → Создать терминал».
2. Для первого локального репозитория выполните команды ниже. Вместо примеров укажите свои имя и почту. Настройки автора здесь применяются к этому проекту.

```sh
git init
git config user.name "Ваше имя"
git config user.email "Ваша почта"
git status
git add .
git status
git commit -m "Добавить атлас росписей, поиск и интерактивные статьи"
git branch -M main
```

3. В GitHub создайте пустой публичный репозиторий для сдачи. Если у вас уже есть репозиторий с предыдущей версией, скопируйте обновлённые файлы в его рабочую папку, сохраните изменения коммитом и используйте существующий origin.
4. Для нового репозитория замените адрес в команде на полный HTTPS-адрес своего репозитория, затем отправьте код.

```sh
git remote add origin https://github.com/ВАШ-ЛОГИН/ВАШ-РЕПОЗИТОРИЙ.git
git push -u origin main
```

5. В Settings → Pages выберите Deploy from a branch, ветку main и папку /docs. Нажмите Save. После успешной публикации откройте ссылку со страницы Pages и проверьте переход из каталога в статью. Эту ссылку можно отправить преподавателю.
